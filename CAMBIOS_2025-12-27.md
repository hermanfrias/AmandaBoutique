# Mejoras al Módulo de Alquiler - Diciembre 2025

**Fecha:** 27-28 de Diciembre de 2025

## Resumen de Cambios

Se realizaron mejoras significativas al módulo de alquiler para mejorar el seguimiento de pagos, agregar depósitos de garantía a los vestidos, y optimizar el contrato PDF.

---

## 1. Sistema de Pagos Mejorado

### Estructura de Pagos

El sistema ahora maneja los pagos de forma más clara y precisa:

**Campos Editables:**

- **Anticipo** - Primer pago del cliente
- **Pago Final/Liquidación** - Segundo pago para completar la deuda
- **Monto Final** - Precio del alquiler del vestido
- **Depósito** - Depósito de garantía del alquiler

**Campos Calculados Automáticamente:**

- **Pago Total Recibido** = Anticipo + Pago Final
- **Total a Pagar** = Monto Final + Depósito
- **Saldo Pendiente** = Total a Pagar - Pago Total Recibido
- **Total en USD** - Conversión automática según tipo de moneda
- **Pago Total en USD** - Conversión automática del pago total

### Conversión Automática de Moneda

El sistema obtiene la tasa de cambio de `ConfiguracionIVA` y convierte automáticamente:

- Si el alquiler es en **Bs**, convierte a USD usando la tasa del día
- Si el alquiler es en **$**, usa los valores directamente

### Ejemplo de Cálculo

```
Monto Final: $100
Depósito: $50
Total a Pagar: $150

Anticipo: $50
Pago Final: $70
Pago Total Recibido: $120 (calculado)

Saldo Pendiente: $30 (calculado)
```

## 2. Depósito de Garantía en Vestidos

### Nuevo Campo: `deposito_garantia`

Cada vestido ahora tiene su propio monto de depósito de garantía configurable:

```python
deposito_garantia = models.DecimalField(
    max_digits=10,
    decimal_places=2,
    verbose_name='Depósito de Garantía',
    default=0
)
```

**Beneficios:**

- Diferentes vestidos pueden tener diferentes depósitos según su valor
- Se muestra en el contrato PDF
- Visible en formularios y detalles del vestido

---

## 3. Actualización Automática de Estados

### Estados de Vestido

El sistema actualiza automáticamente el estado del vestido según el estado del alquiler:

| Estado del Alquiler | Acción en el Vestido  |
| ------------------- | --------------------- |
| **Nuevo alquiler**  | Estado → "Alquilado"  |
| **Cancelado**       | Estado → "Disponible" |
| **Devuelto**        | Estado → "Tintorería" |

### Filtrado en Página Principal

Los vestidos con los siguientes estados NO se muestran en la página principal:

- Dañado
- Vendido
- Baja

## 4. Mejoras al Contrato PDF

### Optimización de Espacio

El contrato PDF fue optimizado para ser más compacto:

**Cambios de Diseño:**

- Reducción de márgenes de página: `2cm 2.5cm` → `1.5cm 2cm`
- Tamaño de fuente del cuerpo: `11pt` → `8.5pt`
- Interlineado: `1.6` → `1.3`
- Organización en dos columnas para datos del contrato
- Cuadro de observaciones ampliado: `40px` → `80px`

**Información Agregada:**

- C.I. del cliente
- Dirección del cliente
- Depósito de garantía del vestido
- Pago Final/Liquidación
- Pago Total Recibido

**Resultado:** El contrato ahora cabe en **2 páginas** en lugar de 3.

## 9. Uso del Sistema

### Crear un Alquiler

1. Seleccionar cliente y vestido
2. Ingresar fechas
3. Ingresar **Anticipo** (primer pago)
4. Ingresar **Monto Final** (precio del alquiler)
5. Ingresar **Depósito** (garantía del alquiler)
6. El sistema calcula automáticamente:
   - Pago Total Recibido = Anticipo
   - Saldo Pendiente = (Monto Final + Depósito) - Anticipo

### Registrar Pago Final

1. Editar el alquiler
2. Ingresar **Pago Final/Liquidación**
3. El sistema recalcula automáticamente:
   - Pago Total Recibido = Anticipo + Pago Final
   - Saldo Pendiente = (Monto Final + Depósito) - Pago Total

---

## 10. Notas Técnicas

- Todas las conversiones de moneda usan la tasa de cambio de `ConfiguracionIVA`
- Los cálculos se realizan en el método `save()` del modelo
- El JavaScript en formularios proporciona feedback inmediato
- El depósito del vestido es independiente del depósito del alquiler
